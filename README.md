## 真实评价和几个要注意的坑

App Store 上图图记账的评分在 4.8 分左右，评价数量接近 4 万条，这个体量在独立记账 App 里算相当扎实。公开评论里被提得最多的优点是界面好看、截屏记账省事，从其他记账 App 迁移过来的用户评价普遍正面。中文测评站和社区里针对这款的独立深度测评不多，能找到的多是功能介绍式的收录页，比如新趣集上的条目，把这套功能列得比较全：桌面小组件、快速记账模式、周期账单自动记录、100 多种货币和自动汇率、资产账户管理、统计图表、还款提醒。这些是 App 的整体能力，不代表全部免费。

缺点和限制说具体一点：

**只能用在苹果设备上。** 没有安卓版，没有网页版。你的数据跟着 Apple ID 走，换手机登录同一个 Apple ID 会自动同步，但也意味着你被锁在苹果生态里。

**买断不等于即时到账。** 下单时要在指定位置填你的 RevenueCat ID，这个 ID 得从 App 里「设置 > 其他 > RevenueCat ID」自己复制出来。填完之后不是立刻生效，官方说明里写的是等待约 1 个工作日处理，收到邮件后才能在 App 内看到会员状态。填错 ID 或者复制时漏了字符，就得联系客服重来一遍，激活前多核对两遍。

**数字商品交付后不退。** 荔枝商店的购买须知写得很直白：数字商品一经交付，除法律要求或特定售后政策外，售出不退不换。所以顺序别搞反，先下载免费版确认软件能在你的设备上正常跑、界面你也能接受，再下单。

**“永久”这两个字的责任方是开发商，不是商店。** 购买须知里明确写了，“永久”“一次购买”“永久更新”这类表述基于开发商提供的信息，后续的更新维护和政策变更由开发商负责，商店不承担赔偿或退款责任。开发商的公开说法是这款采用真正的永久买断，不是大版本买断，后续更新和高级功能都不再收费。这个承诺目前看是兑现的，但你要清楚兜底的人是谁。

**别把它和加密钱包搞混。** 再强调一次，网上大量 “TOTO Wallet” 的内容讲的是区块链资产钱包，和图图记账毫无关系。搜资料的时候认准“图图记账”这四个字。

## 常见问题

**图图记账有安卓版吗？**
没有，目前只支持 iOS，包括 iPhone、iPad 和 Apple Watch。

**买了永久会员，以后大版本更新还要再付钱吗？**
开发商的说明是不需要，所有更新和高级功能都包含在内。这个承诺由开发商负责执行，商店不为其兜底。

**会员到期后我的账目数据会消失吗？**
不会。数据通过 iCloud 存在你自己的设备上，会员到期只是高级功能用不了，记录都还在。买断的话不存在到期这回事。

**换手机数据会丢吗？**
登录同一个 Apple ID 就会同步过来。建议换机前手动确认一次 iCloud 备份状态。

**可以退款吗？**
数字商品交付后原则上不退不换。先试用免费版是最稳妥的做法。
